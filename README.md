📊 Production Dashboard – Excel Analytics Project
📌 Project Overview

The Production Dashboard is an interactive Excel-based analytics solution designed to monitor and evaluate key manufacturing performance metrics.
This dashboard provides a complete view of production output, cost distribution, task allocation, and efficiency trends across different managers, regions, and product categories.

The dashboard uses Pivot Tables, Pivot Charts, Slicers, and 3D Visualizations to help business teams quickly interpret production data and make informed decisions.

🎯 Objectives

The primary goals of this dashboard are:

To visualize production cost performance across product types.

To track total units produced over time (monthly & yearly).

To analyze workload distribution through the number of tasks completed by each manager.

To monitor average production cost per unit using an interactive pie chart.

To enable dynamic exploration using filter slicers (Region, Gender, Age Groups, Quarters).

🧩 Key Features of the Dashboard

The dashboard includes slicers for:

Region

Gender

Age Groups

Quarters (Q1–Q4)

Workload of each manager

Highest performers (e.g., Nancy Grey – 2190 tasks)

Total tasks completed across the team

🔹 3. Production Cost Analysis

A 3D column chart showcasing:

Total production cost for each product category:

Automobiles

Electronics

Furniture

Machinery

Useful for budgeting, tracking expenses, and comparing product cost variations.

🔹 4. Total Unit Production Trend

A line chart showing:

Monthly production data for 2023–2024

Seasonal spikes and drops in production

Year-over-year performance comparison

Great for forecasting and understanding operational cycles.

🔹 5. Average Production Cost per Product Type

A 3D pie chart showing:

Average cost per unit for each product type
(e.g., Furniture: 180, Automobiles: 141)

This helps determine which products are more cost-efficient.

Product types & production costs

All visuals are directly linked to PivotTables to support real-time updates.

🚀 How to Use the Dashboard

Open the Excel file.

Use slicers (Region, Gender, Age Groups, Quarter) to filter insights.

Hover over charts to view exact values.

Modify data in the source sheet — charts update instantly.

Use “Grand Totals” for high-level summaries.

📌 Business Insights From Dashboard

Automobiles have the highest production cost, indicating a capital-heavy category.

Furniture has the highest average cost per unit (180).

Task distribution shows a clear imbalance — Nancy Grey handles significantly more tasks.

Monthly production peaks around Feb–Mar, while dips occur around May and Sep.

Total units produced show strong performance in 2024 (23,556 units).
